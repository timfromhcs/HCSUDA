# HCSUDA installer (V1 release candidate)

## Deliverable

`HCSUDA-Setup-x64.exe` is a **single native executable** built from
`tools/hcsuda_setup/main.cpp`. It embeds the release files in a bounded TLV payload generated by
`installer/embed_payload.py` at build time. No external packager, 7-Zip, Python, CMake, Visual
Studio or Vulkan SDK is needed on the end-user machine.

Build:

```powershell
cmake --preset windows-tests
cmake --build --preset windows-tests --parallel
powershell -NoProfile -ExecutionPolicy Bypass -File installer\make_installer.ps1
```

The last step copies the built setup EXE into `artifacts/` and writes
`artifacts/HCSUDA-Setup-x64.exe.sha256`.

## Runtime behaviour

1. Validates the embedded payload header, file count (<= 256), names (no separators or `..`)
   and per-file sizes (<= 64 MiB).
2. Extracts to a unique directory under `%TEMP%`.
3. Launches `powershell.exe -NoProfile -ExecutionPolicy Bypass -File install.ps1 -Quiet` via
   `CreateProcessW` with an argv string (no shell interpretation of user input).
4. Waits for completion, removes the temporary directory and returns the script exit code.

The installer runs silently, requests **no elevation**, and writes only to:

* `%LOCALAPPDATA%\Programs\HCSUDA` — binaries and license notices;
* `%LOCALAPPDATA%\HCSUDA\{Logs,Models}` — empty user directories;
* a per-user Start Menu shortcut (optional, failure is non-fatal).

It never writes to `System32`, `DriverStore`, Vulkan ICD registry keys, NVIDIA/AMD driver folders,
global PATH, or any system DLL location. It does not install or replace a GPU driver. If no
Vulkan ICD exists, the installed CPU backend still works.

## Uninstall

`uninstall.ps1` in the install directory removes only HCSUDA-installed files and its shortcut.
User models, caches and config under `%LOCALAPPDATA%\HCSUDA` are preserved unless
`-RemoveData` is explicitly passed.

## Verification evidence

* `tests/installer/test_installer.ps1` stages a package, installs into a disposable directory,
  verifies every expected file, runs the installed `hcsdoctor --json`, uninstalls and checks that
  `%WINDIR%\System32\vulkan-1.dll` still exists. Result: `INSTALLER_TEST_PASS`.
* A full end-to-end run of `artifacts/HCSUDA-Setup-x64.exe` on the reference machine returned
  `SETUP_EXIT=0`, installed the binaries, `hcsdoctor --json` reported the real Radeon 680M and
  CPU devices, and uninstall preserved user data.
* SHA-256 is written for every build; the installer is **unsigned** (no publisher certificate is
  configured) and this is stated plainly rather than faked.

## Not done

* Code signing and SBOM attachment to a GitHub Release.
* Upgrade-from-previous-version test and clean-VM test (only the reference machine was used).
* MSI/enterprise deployment; the quiet path is the silent EXE plus the install script.
